Neo4j + AWS Bedrock

GraphRAG Workshop

A hands-on workshop on building GraphRAG (Graph Retrieval-Augmented Generation) applications with Neo4j and AWS Bedrock, using SEC 10-K financial filing data. It progresses from no-code visual exploration to building custom agents over a knowledge graph.

Start the workshop View the slides View on GitHub
Part 1 · Setup & Visual Exploration Stand up Neo4j Aura, load the SEC financial knowledge graph, and explore companies, products, and risk factors visually with Cypher.
Part 2 · Python GraphRAG Build GraphRAG with the Strands Agents SDK and the neo4j-graphrag library — vector and vector-cypher retrievers backed by Bedrock embeddings.
Part 3 · Agents & Pipeline Search the graph through MCP agents and build a GraphRAG data pipeline that loads, embeds, and retrieves over the knowledge graph.

= Workshop Slides

Eight presentation decks accompany this workshop. They provide the conceptual background behind each part: the business case for GraphRAG, the AWS and Neo4j architecture, graph and GraphRAG foundations, retriever patterns, the GraphRAG agent with AgentCore, agent memory, and the Neo4j MCP agent. Presenters can walk through them before the hands-on labs, and self-paced attendees can read them for the theory behind the code.

The decks are published as a standalone slide gallery. Open any deck below, or browse the full https://neo4j-partners.github.io/neo4j-bedrock-graphrag-workshop/slides/[slide gallery]. The table follows the workshop run of show.

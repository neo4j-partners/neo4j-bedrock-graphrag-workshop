= Lab 0: Sign In to AWS

Lab 0 is where the workshop starts. You sign in to AWS, either with the workshop OneBlink credentials or your own account, and enable Amazon Bedrock model access so the coding labs can call Anthropic Claude and Amazon Titan Text Embeddings V2.

TIP: Ready to start? Jump to xref:lab0-instructions.adoc[Lab 0 Instructions: Sign In to AWS] for step-by-step directions.

.**At a Glance**

* **AWS Console access**: sign in through workshop-provided OneBlink credentials or your own AWS account
* **Amazon Bedrock model access**: enable Anthropic Claude (reasoning and tool use) and Amazon Titan Text Embeddings V2 (`amazon.titan-embed-text-v2:0`, 1024-dimension) for embeddings
* **Region**: use `us-east-1` (US East, N. Virginia) for the widest model availability

== Amazon Bedrock

Amazon Bedrock is a managed service that provides API access to foundation models from multiple providers. This workshop uses two models:

* **Anthropic Claude** for reasoning, tool selection, and response generation
* **Amazon Titan Text Embeddings V2** (`amazon.titan-embed-text-v2:0`, 1024 dimensions) for generating vector representations of text chunks

Model access is not enabled by default. You enable access to both models as part of this lab so the coding labs in Part 2 can call them. Use the **US East (N. Virginia) / us-east-1** region for the widest model availability.

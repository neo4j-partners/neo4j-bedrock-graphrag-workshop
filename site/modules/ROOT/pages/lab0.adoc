== Neo4j Aura

Neo4j Aura is a fully managed cloud graph database service. It provides the Neo4j graph engine without the operational overhead: automatic backups, high availability, and deployment on AWS, GCP, or Azure. For this workshop, each participant provisions their own Aura instance from the free trial to hold the SEC financial knowledge graph.

.Vector search, Graph Data Science, and AI capabilities
[%collapsible]
====
Aura provides capabilities beyond the core graph engine that support AI retrieval pipelines. Built-in vector indexes store embeddings alongside graph data, enabling semantic similarity search without a separate vector store. Cypher queries can combine vector search with graph traversal in a single operation. Graph Data Science algorithms like PageRank and community detection run directly within Aura. These capabilities come together in Lab 3 (semantic search and GraphRAG) and Lab 6 (the Neo4j MCP agent).
====

== The SEC 10-K Dataset

The workshop builds a knowledge graph from SEC 10-K financial filings. The dataset captures public companies, the products they offer, the risks they disclose, the institutions that own them, and the filings themselves. It gives you realistic, connected data to query, visualize, and retrieve over throughout the workshop.

The structured entities are:

[cols="1,3"]
|===
| Entity Type | Examples

| **Company**
| NVIDIA, Microsoft, Apple, Amazon, Tesla, JPMorgan Chase, Goldman Sachs, Johnson & Johnson, Pfizer

| **Product**
| GPUs, Cloud Services, iPhone, AWS, Model S, Investment Banking

| **RiskFactor**
| Supply Chain Disruption, Regulatory Compliance, Cybersecurity Threats

| **AssetManager**
| BlackRock, Vanguard, State Street, Fidelity

| **Document**
| The 10-K filings themselves, identified by accession number

| **FinancialMetric**
| Reported financial figures tied to a company and reporting period
|===

== What the Seed Load Provides

Running Lab 0 loads a complete graph in two layers.

**The structured graph** holds the entity types above, connected by typed relationships: a Company OFFERS products, FACES_RISK on risk factors, COMPETES_WITH and PARTNERS_WITH other companies, and REPORTS financial metrics, while an AssetManager OWNS companies and a Company FILED documents.

**The unstructured layer** connects those entities to the text of the filings. Each Document links to Chunk nodes that hold passages of filing text, and each Chunk carries an embedding vector. The seed load populates these embeddings using Amazon Titan Text Embeddings V2 (`amazon.titan-embed-text-v2:0`), which produces 1024-dimension vectors, and it creates the `chunkEmbeddings` vector index over `Chunk.embedding` so semantic search works immediately.

IMPORTANT: After Lab 0, the graph is complete. Both layers are in place, so Labs 3 through 6 run without you having to run the optional data pipeline in Lab 2. Lab 2 is available if you want to see how the unstructured layer is built, but it is not required.

== Aura Developer Tools

The Aura console provides three tools you will use throughout the workshop.

**Query** is a developer environment for writing and executing Cypher queries with syntax highlighting, auto-completion, and saved query collections. You will use this to load data and verify results.

**Explore** (powered by Neo4j Bloom) provides visual graph exploration through an interactive canvas. Search for nodes by label or property, expand their relationships, and discover patterns visually.

**Dashboards** offer low-code data visualization including bar charts, geographic maps, and graph visualizations for presenting graph data to non-technical stakeholders.

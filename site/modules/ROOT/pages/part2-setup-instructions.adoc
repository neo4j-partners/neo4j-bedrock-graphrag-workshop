= Environment Setup Instructions

Follow these steps to set up Amazon SageMaker Studio for the Part 2 coding labs.

TIP: For concepts and background, see xref:part2-setup.adoc[Environment Setup: AWS and SageMaker].

IMPORTANT: Every coding lab reads your Neo4j credentials from the `CONFIG.txt` file at the repository root. After you clone the repository (Step 7), you must fill in `CONFIG.txt` with the credentials you saved in Lab 1 (see <<Step 8: Configure CONFIG.txt with Your Neo4j Credentials>>). The notebooks will fail to connect until this is done.

== Prerequisites

* Completed xref:lab0.adoc[Lab 0]: signed in to AWS with Amazon Bedrock model access enabled

== SageMaker Studio Setup

=== Step 1: Navigate to SageMaker AI

1. In the AWS Management Console, click the **region selector** in the upper right corner and select **US East (N. Virginia)** / `us-east-1`
2. In the search bar at the top, type `SageMaker`
3. Select **Amazon SageMaker AI** from the results

IMPORTANT: Select **Amazon SageMaker AI**, not "Amazon SageMaker." They are different services.

IMPORTANT: SageMaker Studio must be set up in the **US East (N. Virginia) / us-east-1** region. Verify the region selector in the upper right corner shows `us-east-1` before proceeding.

image::Select_SageMaker_East_1.png[Navigate to SageMaker AI in us-east-1]

=== Step 2: Set Up a Domain

1. Verify you see **Amazon SageMaker AI** in the left sidebar
2. In the left panel under "Environment configuration", click **Domains**, then click the **Create domain** button in the top right corner

image::lab3-create-domain.png[SageMaker AI Domains page showing Domains menu and Create domain button]

. Select **Set up for single user (Quick setup)** on the left, then click the **Set up** button. This creates a domain with default settings.

image::lab3-setup-single-user.png[Set up SageMaker Domain page showing Set up for single user option]

=== Step 3: Open SageMaker Studio

1. Wait while your environment is being set up (this takes 1-2 minutes)
2. You will see progress indicators for IAM role creation, internet access, encryption, and storage
3. Once setup completes, click **Open Studio** at the bottom of the page

image::lab3-open-studio.png[Open Studio]

=== Step 4: Launch JupyterLab

1. In SageMaker Studio Home, you will see the Overview tab with workflow options
2. Click the **JupyterLab** card to create and run Jupyter notebooks in a dedicated environment

image::lab3-open-jupyterlab.png[Open JupyterLab]

=== Step 5: Create a JupyterLab Space

1. Under **Space templates**, find the **Quick start** option (ml.t3.medium - 5 GB - 4 GiB RAM)
2. Click **Launch now** to create a lightweight development environment

image::lab3-quick-start.png[Quick Start Launch]

=== Step 6: Open Your Space

1. Wait for the **Status** column to show **Running** (this may take 1-2 minutes)
2. Once running, click on the space name (e.g., **quickstart-default-t...**) in the Name column to open JupyterLab

image::lab3-open-space.png[JupyterLab spaces list showing Running status and space name to click]

=== Step 7: Clone the Git Repository

1. Click the **Git icon** in the left sidebar (it looks like a diamond/branch symbol)
2. If a **Clone a Repository** button is visible, click it and enter the repository URL:
+
----
https://github.com/neo4j-partners/neo4j-bedrock-graphrag-workshop.git
----
+
If the clone button is not available, open a terminal instead:
+
a. In the JupyterLab Launcher, click **Terminal** under the **Other** section
+
image::click-terminal.png[JupyterLab Launcher showing the Terminal option under the Other section]
+
b. Run these commands to clone the repository:
+
[source,bash]
----
git clone https://github.com/neo4j-partners/neo4j-bedrock-graphrag-workshop.git
----
+
3. Once the clone completes, click the **file browser icon** (folder icon) in the left sidebar to navigate into the `neo4j-bedrock-graphrag-workshop` directory

=== Step 8: Configure CONFIG.txt with Your Neo4j Credentials

The repository includes a `CONFIG.txt` file at its root with placeholder values. The notebooks read your Neo4j connection details from this file, so you must fill it in before running any lab.

1. In the JupyterLab file browser, open `CONFIG.txt` in the `neo4j-bedrock-graphrag-workshop` directory
2. Replace the placeholder values with the Neo4j credentials you saved in Lab 1:
+
[source,text]
----
NEO4J_URI=neo4j+s://xxxxxxxx.databases.neo4j.io
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your-password-from-lab-1
----
+
3. Save the file (Cmd/Ctrl+S)

IMPORTANT: `MODEL_ID` and `REGION` already have working defaults, so leave them unchanged. Only the three Neo4j values are required to run Labs 3 and 4.

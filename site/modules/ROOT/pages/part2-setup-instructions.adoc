= Environment Setup Instructions

Follow these steps to sign in to AWS, enable Bedrock model access, and launch Amazon SageMaker Studio for the Part 2 coding labs.

TIP: For concepts and background, see xref:part2-setup.adoc[Environment Setup: AWS and SageMaker].

There are two sign-in paths depending on your situation:

* <<Option A: Workshop Event (OneBlink)>>: for instructor-led workshop participants with an event code
* <<Option B: Using Your Own AWS Account>>: for self-paced learners using a personal or company AWS account

== Prerequisites

* For **Workshop Event**: An event code from your instructor and the email you registered with
* For **Own Account**: An AWS account with IAM permissions for Bedrock

== Option A: Workshop Event (OneBlink)

If you are attending an instructor-led workshop:

1. Visit https://events.oneblink.ai[events.oneblink.ai]
2. Enter the email you used to register along with the 7-digit event code
3. Check the box to agree to the Terms and Conditions, then click **Register**

image::lab0-oneblink-register.png[OneBlink Registration]

Check your mailbox for the OneBlink validation code.

image::lab0-validation-email.png[Validation Email]

Enter your email, the event code, and the validation code from your email, then click **Access Sandbox**.

image::lab0-access-sandbox.png[Access Sandbox]

Once validated, you will receive your AWS credentials. **Save this information.** You will need it for all subsequent labs. These accounts are terminated at the end of the workshop.

== Option B: Using Your Own AWS Account

1. Ensure you have an IAM user with permissions for:
** Amazon Bedrock (model access and agent creation)
** CloudFormation (for CDK deployment)
2. Create access keys for programmatic access if needed for later labs

== Sign into AWS Console

1. Open the AWS Console at https://console.aws.amazon.com/[console.aws.amazon.com]
2. Enter your Account ID (or account alias) and click **Next**
3. Enter your IAM username and password, then click **Sign in**

image::lab0-aws-console-home.png[AWS Console Home]

== Select the Correct Region

Amazon Bedrock is available in select regions. For this workshop, use **US East (N. Virginia) - us-east-1** for the widest model availability.

1. Click the region selector in the top-right corner of the console
2. Select **US East (N. Virginia)**

== Enable Bedrock Model Access

1. In the AWS Console search bar, type **Bedrock** and select **Amazon Bedrock**
2. In the left sidebar, click **Model access** to verify which models are available

NOTE: If this is your first time using Bedrock, you may need to request access to specific models. Click **Manage model access**, enable **Amazon Titan Text Embeddings V2** (usually approved instantly) and **Anthropic Claude** (may take a few minutes), then click **Save changes**.

== SageMaker Studio Setup

=== Step 1: Navigate to SageMaker AI

1. In the AWS Management Console, click the **region selector** in the upper right corner and select **US East (N. Virginia)** / `us-east-1`
2. In the search bar at the top, type `SageMaker`
3. Select **Amazon SageMaker AI** from the results

IMPORTANT: Select **Amazon SageMaker AI**, not "Amazon SageMaker." They are different services.

IMPORTANT: SageMaker Studio must be set up in the **US East (N. Virginia) / us-east-1** region. Verify the region selector in the upper right corner shows `us-east-1` before proceeding.

image::Select_SageMaker_East_1.png[Navigate to SageMaker AI in us-east-1]

=== Step 2: Set Up a Domain

1. Verify you see **Amazon SageMaker AI** in the left sidebar
2. In the left panel under "Environment configuration", click **Domains**, then click the **Create domain** button in the top right corner

image::lab3-create-domain.png[SageMaker AI Domains page showing Domains menu and Create domain button]

. Select **Set up for single user (Quick setup)** on the left, then click the **Set up** button. This creates a domain with default settings.

image::lab3-setup-single-user.png[Set up SageMaker Domain page showing Set up for single user option]

=== Step 3: Open SageMaker Studio

1. Wait while your environment is being set up (this takes 1-2 minutes)
2. You will see progress indicators for IAM role creation, internet access, encryption, and storage
3. Once setup completes, click **Open Studio** at the bottom of the page

image::lab3-open-studio.png[Open Studio]

=== Step 4: Launch JupyterLab

1. In SageMaker Studio Home, you will see the Overview tab with workflow options
2. Click the **JupyterLab** card to create and run Jupyter notebooks in a dedicated environment

image::lab3-open-jupyterlab.png[Open JupyterLab]

=== Step 5: Create a JupyterLab Space

1. Under **Space templates**, find the **Quick start** option (ml.t3.medium - 5 GB - 4 GiB RAM)
2. Click **Launch now** to create a lightweight development environment

image::lab3-quick-start.png[Quick Start Launch]

=== Step 6: Open Your Space

1. Wait for the **Status** column to show **Running** (this may take 1-2 minutes)
2. Once running, click on the space name (e.g., **quickstart-default-t...**) in the Name column to open JupyterLab

image::lab3-open-space.png[JupyterLab spaces list showing Running status and space name to click]

=== Step 7: Create a Labs Folder

1. In the JupyterLab file browser on the left, click the **Create New Folder** icon (folder with a + sign)
2. Name the folder `labs` and press Enter
3. Double-click the **labs** folder to open it

image::lab3-create-folder.png[Create Folder]

=== Step 8: Clone the Git Repository

1. Click the **Git icon** in the left sidebar (it looks like a diamond/branch symbol)
2. If a **Clone a Repository** button is visible, click it and enter the repository URL:
+
----
https://github.com/neo4j-partners/neo4j-bedrock-graphrag-workshop.git
----
+
If the clone button is not available, open a terminal instead:
+
a. In the JupyterLab Launcher, click **Terminal** under the **Other** section
b. Run these commands to clone the repository:
+
[source,bash]
----
git clone https://github.com/neo4j-partners/neo4j-bedrock-graphrag-workshop.git
----
+
3. Once the clone completes, click the **file browser icon** (folder icon) in the left sidebar to navigate into the `labs/neo4j-bedrock-graphrag-workshop` directory

= Part 2: AWS ETL, Semantic Search, and GraphRAG

This part is the core of the workshop. You set up the AWS environment, add the unstructured layer to the knowledge graph, and build retrieval that spans both the structured graph and the vector-indexed text.

You will work in Amazon SageMaker Studio, use the neo4j-graphrag Python library for semantic search and GraphRAG retrieval, and build a Strands agent that combines vector search with graph traversal and deploys to Amazon Bedrock AgentCore.

image::two-layer-graph.png[The Two-Layer Graph,800]

== The neo4j-graphrag Library

Lab 3 uses the https://github.com/neo4j/neo4j-graphrag-python[neo4j-graphrag] Python library, which provides the building blocks for GraphRAG applications on Neo4j. The library includes retriever classes (`VectorRetriever`, `VectorCypherRetriever`) that handle embedding, vector search, and graph traversal, a `GraphRAG` pipeline class that combines retrieval with LLM generation, and pluggable LLM and embedder abstractions for providers including Bedrock, OpenAI, and Anthropic. The optional data pipeline in Lab 2 uses the library's knowledge graph construction components to build the graph from scratch.

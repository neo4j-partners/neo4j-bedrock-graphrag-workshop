= Lab 3 Instructions: Semantic Search and GraphRAG

Follow these notebooks to build retrieval pipelines against your knowledge graph, progressing from pure vector search to graph-enriched retrieval. The unstructured layer (chunks, Titan v2 embeddings, and the `chunkEmbeddings` index) is already in place from the Lab 1 seed load, so both notebooks start directly with retrieval.

TIP: For concepts and background, see xref:lab3.adoc[Lab 3: Semantic Search and GraphRAG].

== What You'll Learn

* **Vector Search**: Use `VectorRetriever` to find semantically similar chunks and generate answers with the `GraphRAG` pipeline
* **Graph-Enriched Search**: Use `VectorCypherRetriever` to combine vector search with Cypher graph traversal for richer context

== Prerequisites

* Completed **Lab 1**: Aura instance created and the seed load run (structured entities plus the unstructured chunk/embedding layer)
* Completed the **Part 2 environment setup**: see xref:part2-setup-instructions.adoc[Part 2 Setup Instructions]

NOTE: This lab uses the same Neo4j Aura instance from Part 1. The seed load already added both the structured graph (companies, products, risk factors, asset managers) and the unstructured layer (chunks with Titan v2 embeddings and the `chunkEmbeddings` vector index). These notebooks read from that graph; they do not clear or reload data.

=== Update CONFIG.txt with Neo4j Credentials

Before running the notebooks, open `CONFIG.txt` at the repository root and fill in the Neo4j credentials you saved in Lab 1:

[source,text]
----
NEO4J_URI=neo4j+s://xxxxxxxx.databases.neo4j.io
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your-password-from-lab-0
----

`MODEL_ID` and `REGION` are pre-configured with working defaults. The embedding model is Amazon Titan Text Embeddings V2 (`amazon.titan-embed-text-v2:0`), which produces 1024-dimensional vectors matching the `chunkEmbeddings` index.

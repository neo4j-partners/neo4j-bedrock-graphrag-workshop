= Lab 2 Instructions: Chunking and Embeddings

TIP: For concepts and background, see xref:lab2.adoc[Lab 2: Data Pipeline].

== What You'll Learn

* **Chunking**: Split SEC 10-K filing text into overlapping passages sized for embedding
* **Embeddings**: Generate 1024-dimensional vectors with Amazon Titan Text Embeddings V2
* **Graph pipeline**: Store chunks, embeddings, and their relationships alongside structured Company, Product, and Document entities
* **Vector search**: Create a vector index and run a semantic query with `VectorRetriever`

== Prerequisites

* Completed **Lab 1** (Neo4j Aura instance created and running with the seed data load)
* Completed the Part 2 environment setup (xref:part2-setup-instructions.adoc[Part 2 Setup Instructions])
* A running environment (SageMaker Studio or GitHub Codespace)

NOTE: This lab is optional and non-destructive. It builds everything in an isolated sandbox using `:Demo` node labels and a `demoChunkEmbeddings` index, then tears the sandbox down at the end. The graph Lab 1 loaded is never touched, so the notebook is safe to run as many times as you like.

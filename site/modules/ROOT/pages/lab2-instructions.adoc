= Lab 2 Instructions: Data Pipeline

TIP: For concepts and background, see xref:lab2.adoc[Lab 2: Data Pipeline].

== What You'll Learn

* **Data Loading**: Build a two-layer knowledge graph from raw SEC 10-K filing data, including structured entities and unstructured document chunks connected by cross-links
* **Embeddings**: Generate vector embeddings with Amazon Titan Text Embeddings V2 and create a vector index for semantic search
* **VectorCypherRetriever**: Vector search enriched with Cypher graph traversal to connected entities, wired into a GraphRAG pipeline

== Prerequisites

* Completed **Lab 1** (Neo4j Aura instance created and running with the seed data load)
* Completed the Part 2 environment setup (xref:part2-setup-instructions.adoc[Part 2 Setup Instructions])
* A running environment (SageMaker Studio or GitHub Codespace)

NOTE: This lab wipes the graph and rebuilds from scratch using `financial_data.json`, reproducing the full workshop graph so the rest of Part 2 still works afterward.

== Notebooks

Open each notebook in order. Each one builds on the graph state left by the previous notebook.

[cols="1,2,3"]
|===
| Notebook | Title | What You Build

| `Lab_2_Data_Pipeline/01_data_loading.ipynb`
| Data Loading
| Company, Product, RiskFactor, Document, and Chunk nodes linked by `OFFERS`, `FACES_RISK`, `FILED`, `FROM_DOCUMENT`, `NEXT_CHUNK`, and `FROM_CHUNK` relationships

| `Lab_2_Data_Pipeline/02_embeddings.ipynb`
| Embeddings
| Amazon Titan Text Embeddings V2 vectors on every Chunk node, plus a `chunkEmbeddings` vector index

| `Lab_2_Data_Pipeline/03_vector_cypher_retriever.ipynb`
| VectorCypher Retriever
| A `VectorCypherRetriever` that enriches each vector match with document metadata and connected entities via Cypher, wired into a `GraphRAG` pipeline
|===

= Appendix Instructions: What Is an Agent?

Follow these steps to run the basic Strands agent notebook and deploy it to Amazon Bedrock AgentCore.

TIP: For concepts and background, see xref:appendix-agent.adoc[Appendix: What Is an Agent?].

== Prerequisites

* A working environment from xref:part2-setup-instructions.adoc[Environment Setup Instructions]: AWS sign-in, Bedrock model access, and SageMaker Studio with the workshop repository cloned
* `CONFIG.txt` with your MODEL_ID and REGION

== What You'll Learn

* **Amazon Bedrock**: Configure and invoke foundation models from SageMaker notebooks
* **Strands Agent Architecture**: Build agents with a model, tools, and a system prompt
* **Tool Definition**: Define Python functions that an LLM can call with the `@tool` decorator
* **ReAct Pattern**: Reason, act, observe, and repeat in a loop
* **AgentCore Deployment**: Package and deploy an agent to managed AWS runtime
* **Agent Invocation**: Call a deployed agent via CLI and boto3

== Notebook 1: Build and Test the Agent

1. In the file browser, navigate to `zz_Appendix_What_Is_An_Agent/`
2. Open `01_basic_strands_agent.ipynb`
3. The notebook loads configuration from `../CONFIG.txt` (MODEL_ID and REGION)
4. Run through the cells to:
** Install required packages
** Define simple tools (`get_current_time`, `add_numbers`)
** Build and run the Strands agent
** Test the agent with sample queries
** Ask questions about sample SEC financial filing data

== Notebook 2: Deploy to AgentCore Runtime

IMPORTANT: During hosted OneBlink workshops, SageMaker roles do not have the IAM permissions required to run this notebook. You can review the code and concepts, but deployment will only work in your own AWS account with the appropriate permissions configured.

1. In the `zz_Appendix_What_Is_An_Agent/` directory, open `02_deploy_to_agentcore.ipynb`
2. The agent code is pre-built in the `agentcore_deploy/` directory
3. Run through the cells to:
** Review the deployment package (`agent.py` and `pyproject.toml`)
** Configure and deploy the agent to AgentCore Runtime
** Invoke the deployed agent via CLI and boto3

NOTE: The deployment creates AWS resources. When you are finished, uncomment and run the cleanup cell to destroy the deployed agent.

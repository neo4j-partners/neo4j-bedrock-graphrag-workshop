== Amazon SageMaker Studio

The Part 2 labs run as Jupyter notebooks. Rather than install Python locally, you use Amazon SageMaker Studio, a managed development environment that runs JupyterLab in the browser. You create a SageMaker domain, launch a JupyterLab space, and clone the workshop repository into it. Set up SageMaker Studio in the **US East (N. Virginia) / us-east-1** region, the same region you used for Bedrock model access. Every notebook from Lab 2 onward runs from this environment and reads credentials from `CONFIG.txt`.
